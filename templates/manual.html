Cómo descargar un video, extraer audio o procesar una lista de enlaces.

Interfaz web

Abre la página local de Video Downloader. En la pantalla principal encontrarás el campo para enlaces, el selector de formato, la calidad, la carpeta de destino y el botón para comenzar.

Antes de empezarUsa enlaces individuales de YouTube, ya sea de youtube.com o youtu.be. La aplicación procesa cada enlace como un video.

Consultar un video

  1. Pega el enlace en el cuadro Enlace de YouTube.
  2. Pulsa Consultar video.
  3. Revisa la tarjeta con título, canal y duración. Si la consulta funciona, aparecerán las resoluciones MP4 disponibles en el selector de calidad.

Consultar es opcional si quieres descargar con calidad automática. En listas, la vista previa muestra únicamente el primer enlace.

Descargar video o audio

Video

  1. Selecciona Video.
  2. Deja Automática · mejor disponible para que la aplicación elija, o selecciona una resolución después de consultar el video.
  3. Comprueba el destino mostrado y pulsa Descargar ahora.

La descarga de video se guarda como MP4. Si YouTube entrega video y audio por separado, la aplicación los combina.

Solo audio

  1. Selecciona Solo audio. El destino cambia a downloads/audio.
  2. Pulsa Descargar ahora. La calidad de video deja de aplicar.

El audio web se conserva en el formato original disponible, normalmente M4A.

Procesar varios enlaces

Pega cada URL en una línea independiente. Selecciona el mismo modo para toda la tarea: video o audio. La aplicación procesará los enlaces uno por uno y actualizará el estado mientras trabaja.

Al terminar, la ventana de resultados indica cuántos archivos se descargaron. Pulsa Ver archivo para abrir un resultado. Si algún enlace falló, se mostrará su error junto a los archivos completados; los demás enlaces seguirán procesándose.

Usar la versión de consola

La aplicación también tiene un menú en consola, iniciado con python main.py desde el proyecto:

  1. Elige 1 para introducir un enlace o 2 para indicar un archivo de texto con enlaces (uno por línea).
  2. Elige 1 para descarga rápida de video y audio, 2 para video con selección de calidad o 3 para audio.
  3. Para un enlace individual con la opción 2, introduce el número de calidad que aparece en la lista.
  4. Cuando termine, busca los archivos en la ruta configurada en config.py.

En consola, el modo de audio convierte la pista a MP3. Si eliges calidad al procesar un archivo de enlaces, se usa automáticamente la primera calidad listada para cada enlace.

Si algo falla

  • Enlace no válido: comprueba que sea una URL completa de YouTube o youtu.be.
  • No se pudo consultar el video: verifica el enlace y vuelve a intentarlo. Puede que el video no esté disponible para consulta.
  • No aparece la resolución esperada: vuelve a consultar el video. Las resoluciones dependen de la fuente.
  • La tarea termina con errores: revisa los detalles mostrados en la ventana final; los enlaces válidos de la lista se procesan de forma independiente.
  • No encuentras el archivo: revisa la carpeta de destino indicada en pantalla. La interfaz utiliza la carpeta downloads del proyecto si la ruta configurada no está disponible.

Vuelve a Nueva descarga para limpiar el formulario y empezar otra tarea.
