Resumen

Video Downloader ofrece dos maneras de descargar videos o audio de YouTube: una aplicación web local y un programa de consola. La interfaz web permite consultar la información de un video, elegir formato y calidad, procesar varios enlaces y revisar el resultado desde el navegador.

La aplicación web se sirve desde Flask. Las consultas y descargas las realiza yt-dlp; FFmpeg, incluido mediante imageio-ffmpeg, permite combinar pistas cuando se selecciona un formato de video que las ofrece por separado.

Funciones principales

  • Consulta: obtiene título, canal, duración, miniatura y resoluciones MP4 del primer enlace.
  • Descarga de video: guarda video y audio en MP4, con selección automática o una resolución consultada.
  • Descarga de audio: guarda la pista de audio en el formato original disponible, normalmente M4A.
  • Procesamiento por lote: procesa los enlaces no vacíos, uno por línea, de forma secuencial.
  • Estado y resultados: muestra avance, archivos listos y errores individuales al finalizar la tarea.

Componentes

web_app.py

Rutas Flask, validación de enlaces, vista previa, gestión de tareas, descarga y acceso a resultados.

templates/index.html

Página de descarga: formulario, opciones, mensajes y ventana de finalización.

static/app.js

Conecta la interfaz con las rutas API, consulta estado periódicamente y presenta archivos y errores.

static/style.css

Estilos de la aplicación de descarga.

templates/documentation.html y templates/manual.html

Páginas web de documentación técnica y manual de uso.

static/docs.css

Diseño y navegación compartidos por las páginas de documentación.

main.py

Versión de consola: descarga individual o por fichero, selección de calidad y conversión de audio.

config.py y conf_management.py

Ruta base de descargas consultada por la versión de consola y por la interfaz web como ruta preferida.

Flujo de descarga web

  1. El navegador envía los enlaces, el modo (video o audio) y, opcionalmente, el formato elegido a /api/download.
  2. El servidor valida los enlaces y crea una tarea en segundo plano.
  3. El navegador consulta /api/jobs/<id> para mostrar el progreso.
  4. El servidor registra los archivos completados o errores de cada enlace.
  5. Al finalizar, el navegador muestra los resultados. El acceso /api/jobs/<id>/files/<índice> permite abrir el archivo.

La vista previa usa /api/preview y consulta solamente el primer enlace que no esté vacío.

Archivos y formatos

La ruta configurada en config.py es /mnt/d/Youtube. La interfaz web la utiliza si existe como ruta válida en el sistema; de lo contrario, utiliza la carpeta downloads dentro del proyecto. En la interfaz, videos y audios se separan en video y audio.

El modo video solicita MP4 y puede combinar pistas separadas. El modo audio prioriza M4A y conserva el formato de audio que entrega la fuente. En consola, la opción de audio convierte el archivo a MP3 mediante MoviePy.

Comportamiento y límites

  • Solo se aceptan enlaces que comiencen con YouTube o youtu.be.
  • Los parámetros de playlist se ignoran en la consulta y cada enlace se trata como un video individual.
  • La calidad depende de los formatos disponibles para cada video. La lista de calidades se carga al consultar el enlace.
  • Una consulta de vista previa no valida los enlaces adicionales de una lista; cada uno se intenta descargar durante la tarea.
  • Los estados de tarea se mantienen en memoria del proceso de Flask, por lo que no son un historial persistente.

Consulta el manual de uso para seguir el flujo desde la interfaz.
